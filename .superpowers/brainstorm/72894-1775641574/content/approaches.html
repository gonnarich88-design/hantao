3 แนวทาง UX สำหรับ HanTao

เลือกแนวทางที่รู้สึกถูกทิศทางที่สุด — รายละเอียดปรับได้ทีหลัง

① เพิ่มคน + เลือกผู้จ่าย
② เพิ่มรายการ + เลือกว่าใครกิน
③ ดูสรุป + โอนเงิน
แก้ไขย้อนหลังได้ตลอด

A — Guided Wizard

3 ขั้นตอนชัดเจน ตั้งค่าครั้งแรกเป็น wizard หลังจากนั้นแก้ได้อิสระ เหมาะกับ user ใหม่มาก

ข้อดี

  • ไม่สับสน flow ชัดเจน
  • User ใหม่ใช้ได้เลย

ข้อเสีย

  • อาจช้าสำหรับ user เก่า
👥 คน
🧾 รายการ
💰 สรุป
+ เพิ่มรายการ
ข้าวผัด 120฿ · [แอน] [บี] [ซี]
ไก่ทอด 80฿ · [แอน] [บี]

B — Tab Navigation

3 แท็บ: คน / รายการ / สรุป เคลื่อนย้ายได้อิสระ กดดูสรุปได้ตลอดเวลา

ข้อดี

  • เร็ว กระชับ
  • เห็นภาพรวมได้ทันที

ข้อเสีย

  • User ใหม่อาจไม่รู้ว่าเริ่มที่ไหน
① Wizard ครั้งแรก (ตั้งค่าครั้งเดียว)
👥 คน
🧾 รายการ
💰 สรุป
② จบ wizard → แก้ไขอิสระผ่าน tab ได้เลย

C — Wizard → Tab (Hybrid) ⭐ แนะนำ

เริ่มด้วย wizard 2 ขั้นตอนสั้น ๆ (เพิ่มคน + เลือกผู้จ่าย) แล้วเข้า tab interface ปกติ — ดีที่สุดของทั้งสองแบบ

ข้อดี

  • User ใหม่ไม่สับสน
  • User เก่าทำงานได้เร็ว
  • ตรงกับที่คุยกันมา

ข้อเสีย

  • ซับซ้อนกว่าในการ implement
